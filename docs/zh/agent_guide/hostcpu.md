# HostCPU 主机性能调优

`HostCPU` 是面向昇腾 NPU 训练/推理场景 **Host 侧**（CPU / NUMA / 中断 / 绑核）性能的 Agent：审计主机配置、求解 CPU 绑核方案，并对症状不明的 Host 侧瓶颈做归因编排。

## 1. Agent 定位

- 面向 Host 侧配置、绑核与系统级干扰问题，与 NPU 侧的 Profiling 分析分工
- 只做只读采集与方案输出；`taskset` / `sysctl` / `cgroup` 等写操作默认只输出命令，由用户确认后执行
- 适合新机器开箱、换容器、绑核未生效、CPU 利用率上不去、训练变慢等场景

## 2. 核心能力

- **主机配置审计**：采集 NUMA / 绑核 / 大页 / 频率 / 中断 / cgroup / 环境变量 / NPU 适配八个域，按阈值与机型 profile 输出分级判定、组合诊断、待改清单（命令 + 回滚 + 验证）与 HTML 报告
- **绑核与 NUMA 亲和方案**：按 rank / worker / engine 划分核集，输出 `taskset` / `cpuset` / OMP 方案、回滚与验证脚本
- **症状类归因编排**：配置复核 → 归因量化 → 动作排序，输出汇总页与机读索引
- **窄诉求直达**：只要配置检查或绑核方案时直接调用对应 Skill，不额外走编排

## 3. 推荐使用方式

- 说明明确场景（检查配置 / 出绑核方案 / 训练变慢定位）与目标进程或 NPU 卡号
- 需要落地方案时说明执行形态（运行中生效 / 下次启动注入）与当前权限
- 写操作会先给出命令、回滚与验证方法，确认后再执行

## 4. 内置 Skill

| Skill | 用途 |
| --- | --- |
| `msagent-perf-cpu-config-audit` | 主机配置体检：八域单点快照、分级判定、待改清单与 HTML 报告 |
| `msagent-perf-cpu-bind-tune` | 绑核与 NUMA 亲和方案求解：核集划分、plan、回滚与验证脚本 |
| `msagent-perf-cpu-perf-triage` | 症状不明时的编排入口：配置复核 → 归因量化 → 动作排序与汇总页 |

## 5. 边界

- NPU 侧 Profiling 数据分析（`ascend_pt`、算子热点、通信瓶颈、MFU）→ 转 `Profiler`
- 代码/算子改写、NPU 微架构分析不在本 Agent 范围
- 持续时序观测（限流曲线、降频趋势）仅做单点快照与短窗采集
