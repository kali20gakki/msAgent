# 硬约束汇编（唯一权威定义）

> 本文件是全部硬约束的权威定义，每条按「触发条件 → 必须执行 → 违反后果」组织。主 SKILL.md §1 只保留摘要；两者冲突时以本文件为准。约束编号（HC-A1…HC-E3，含子款号①②…）是全库唯一引用键。

## HC-A 信息隔离与输入纪律

**HC-A1 证据来源纪律**（全程）
- 触发：分析全程（候选生成、证据登记、排序、结论撰写）。
- 程序：候选与证据必须由当前 case 的数据（dump/stack/construct 与现象描述）推导。历史或外部结论（上一轮分析报告、结论类文件、任何"答案"）不构成证据：不得据此生成候选、调整位序、补全因果链或直接承报结论；可参考的部分只能以待验证假设形态登记，引用其任何数值或断言前必须按当前数据独立验证。是否读取此类文件由部署方约定。
- 后果：以外部结论承证据、或承报未经当前数据独立验证的历史结论 → 相关主张证据资格无效，从证据链撤下并如实标注。

**HC-A2 输入不可变**：不修改原始输入；所有产物写入独立工作目录。

**HC-A3 无预生成输入**：不接受预生成的 compare CSV 或中间分析结果作为分析输入；不要求用户预先提供本应由本 Skill 生成的分析结果。

**HC-A4 跨案身份锚**
- 触发：报告落盘、恢复/续作。
- 程序：报告标题下第一行固定写 `本报告属于 caseXXX（仅分析 <本 case 数据目录名>）`；一切自指使用完整绝对路径，禁止裸 `report.md` 指代；发现盘中报告内容与本 case 无关（出现其他 case 的算子名/现象主题）→ 立即停写、不在该文件落笔，向调用方报告错锚。

## HC-B 证据资格

**HC-B1 相对显著性判据**
- 触发：任何跨侧分歧的入册、降格、豁免判断。
- 程序：显著性与证据资格只按**相对量**判定——相对差 ≥1e-3、≥10× dtype 噪声地板、或跨侧比值悬殊达 ≥1e2 量级。达到任一判据即为「显著分歧」，必须入册。
- 后果：①禁止以绝对量级（"数值 ≤1e-5，尘埃级"）降格已被相对判据判显著的分歧——绝对量级只用于陈述该分歧对现象主项的贡献占比，不得用于否定证据资格、触发排除或支撑让位；②未排除的 dtype 舍入/网格粒度类假设只能登记为后续验证条目，不得反过来降低已达标分歧的显著性等级、证据资格或所属簇的"作为根因"置信度；③消费点输出相对差 ≥1e-3 一律表述并记录为"显著分歧"。

**HC-B2 措辞纪律**
- 触发：对已记录的 ≥1e-3 显著分歧做后续论证时。
- 程序："可比"只描述 <1e-3 的数值状态，不是"未达定罪强度"的同义词；禁止以"未达可比判据""未见决定性分歧""不构成可比性"类措辞反转已达标分歧的证据地位。显著分歧的证据地位只能被有效域论证（HC-C5）改变，不能被措辞降格。

**HC-B3 引值回查**
- 触发：报告中写入任何"具名节点 + 槽位 + 具体数值"引用（锚点四元组、闭合算术、候选资格表行、候选直接证据条目）。
- 程序：写入前在该侧 dump.json 按节点键 + 槽位路径读回核对；键不存在或值不符时，用全窗值搜索定位真实锚点并改写；全窗无命中的引值**禁止写入**（宁缺毋错——"引值无源"比"值真名错"更重）。③**锚点槽位与自证对照**：first 工具产出的首分歧锚点落账时，必须转录其分歧**槽位名**与该槽双侧四统计量（节点级归属不替代槽位转录）；候选资格表"输入一致性自证"必须附对应输入槽的双侧值引用（证据 ID/查询输出行），无引用的自证无效。分歧槽为 input_args/parameters 类输入槽时，该节点不得登记为"输入一致而输出分歧"的制造节点——其输入差异按 mechanism §3.9 程序六来源定性处置。

**HC-B4 侧别与计数**
- 触发：引用统计量、使用全称量词。
- 程序：①每个统计量标明侧别（T=/G=）；两侧值不同时禁止将单侧值写入双侧共享语境。②全称量词（"全部/恒/无反例/两侧均/逐位"）必须附精确计数（n:m 形式，可由脚本重演）；构成类声明给出精确构成（如"158 X + 2 Y"），禁止以主导成分代替全量。

**HC-B5 数值保真**：引用数值与 dump 可查值逐位一致（确需舍入显示时声明位数）；同一节点同一槽位数值全文各节引用一致。

**HC-B6 排他性断言的普查义务与窗口闭合前提**
- 触发：作出"逐位一致/噪声级一致/窗口内无数值后果/不传播"类全窗口量词性否定断言；或援引消费点反证作让渡。
- 程序：①此类断言必须以分析器**全窗口分歧普查表**为依据（同形状槽位总数、rel≥1e-3 显著数、rel min/max、跨侧比值 ≥1e3× 案例数，forward/backward 分列）并引用具体数字；抽查节点（≤5 个手选例）不得支撑全窗口量词陈述。②census 引用处附口径声明：谓词阈值、槽位 universe、rel 分母约定、求和范围。③消费点反证（HC-C6 让位情形①）仅在现象载体的全部输入内容可由窗口内生产算术闭合时可用；载体输入存在窗口内无生产者的内容（覆盖缺口已证实）时，窗口内消费点一致不能证明任何簇与现象无关，相关簇保持未排除原位序。
- 后果：普查缺失时该断言降为[未验证]，不得参与位序、排除或"无数值后果"论证。

**HC-B7 统计代数三禁**
- 触发：量级/闭合论证中使用统计四元组。
- 程序：①禁以 Δ‖x‖²（=(‖x_T‖−‖x_G‖)(‖x_T‖+‖x_G‖)）冒充 ‖Δx‖²（逐元素差的范数平方，不可由四统计量恢复）；②仅持四统计量时禁对交叉项、夹角、"σ 级对齐"作定量可达性断言（只能给上下界并显式标注"统计型 dump 无元素级信息"）；③"算术不可达/必须由执行侧产生"类结论不得作为簇降位、排除或位序攀升依据。

**HC-B8 多 rank 证据纪律**
- 触发：两侧 dump 路径含多个 rank 目录（rank0..rankN，两侧 rank 布局对应；单 rank 布局不触发）。
- 程序：
①**逐 rank 复核义务**：承重候选族、首分歧族、结构分歧簇、守恒违反族，以及任何拟支撑"窗口级一致/分歧"断言的节点族，必须在**全部 rank** 上复核（`query.py ranks` 一次完成：逐 rank 分桶汇总+显著明细；任一单 rank 的节点抽查不满足本义务）。②**rank 集中性呈报**：分歧只在部分 rank 显形、或量级跨 rank 悬殊时，按 rank 分列数值入册——"rank 集中显形"本身是**承重证据形态**（如反向增益差集中于个别 rank、其余 rank 噪声地板）；不得以单一 rank 的数值代表全分布。③**跨 rank 外推禁令**（与排除迁移禁令同型）：单 rank 上的一致/分歧结论不得外推为窗口级结论；"逐位一致/无承载性分歧产生点"类断言必须注明**rank 有效域**（"rank0 一致"≠"捕获反向一致"）。HC-B6 全窗口否定断言在多 rank 布局下的普查口径=逐 rank 普查或 ranks 工具汇总。
- 后果：多 rank 复核缺失时，相关断言降为[未验证]（rank 域未知），不得参与位序、排除或"无分歧产生点"论证；因单 rank 视角遗漏的分歧制造证据（rank 集中显形）不得以"窗口外/覆盖外机制"兜底归因。

## HC-C 候选资格、位序与根因主语

**HC-C1 现象载体不是候选**
- 触发：候选登记、根因主语表述。
- 程序：现象的观测点（gnorm 现象中的裁剪输入、loss 现象中的最终输出分歧）是待解释对象，不是候选。①现象量在载体槽位/分量上的分布分解（哪些槽位异常、top-k 贡献、聚合值复现现象数值）是现象的槽位级复述，只能作载体证据，不承载根因主语；②对载体自身状态（内容/量级/分布/槽位构成，含"承载非本步产物内容""与窗口内产物不同源"类表述）的刻画是载体状态复述，同失主语资格；③机械判别式（谓语改写测试）：改写句式固定为「载体（或其输入缓冲）＋候选谓语原文」——只把宾语替换为载体/其输入缓冲，谓语保持原文；改写后语义不变=载体状态复述，失格。测试只认该正典句式；禁止以偷换宾语/谓语的变体改写（如改写为"载体/缓冲本身""载体名称"后声称语义改变）通过测试。显式判例："（载体输入）缓冲载有陈旧/非本步产物/参数量级残留内容（写入者未捕获）"改写为"载体（其输入缓冲）载有陈旧内容…"语义不变 → **失格**（本条②明列情形），其归宿=HC-C8③ 回退呈报的覆盖外定位/并列发现，或覆盖内指纹簇因果链的机制层环节（HC-C7）——即使其指纹锚定在第三方节点（生产者反查命中点、反向链节点）也不豁免；④"窗口内无生产者/与反向链脱节"是覆盖缺口事实（定位生产在覆盖外），不是机制语义。载体分解数值（量级差、有界性）不构成对任何机制候选连接的否定。

**HC-C2 根因主语资格**
- 触发：排序第 1 位确定、根因表述落笔。
- 程序：合格根因主语必须有节点/算子/参数身份与机制语义（回答"为什么不同"）。
①**主项解释力与让渡判据**：候选机制若自认不能解释现象定义性主项——核心单侧不对称本体（单侧"有无级"梯度塌缩、单侧守恒违反、单侧量级悬殊等）为何出现、为何偏向一侧——并把主项起源让渡给其他候选或覆盖外环节的，不得承根因主语、位序不得高于能解释主项起源与方向的未排除非背景簇（无此类簇时如实报告"主项起源只能定位到覆盖外"，按 HC-C8 回退呈报）。**让渡判据只认机制形态不兼容**：须论证该候选已验证的机制类型在原理上无法产生现象核心不对称的形态（给出形态对照：现象核心形态 vs 该机制可产生的形态），仅此构成 HC-C6④ 让渡。**以下论证一律不构成让渡依据**：(a) 数值量级占比比较（量级贡献占比是 HC-C3③ 禁止参与位序的论证类型，对让渡同样无效）；(b) "存在验证更强/闭合更完整的竞争候选"（闭合强度不是跨候选排序准则，HC-C3②）。**与最早显形锁定的仲裁**：本款与 HC-C3② 冲突时，维持 HC-C3② 锁定，除非上述形态对照论证成立；同侧多缺陷并存（如一个早期已验证缺陷 + 一个晚期大效应缺陷）不构成任何一方的让渡——两者如实并列呈报，主语归 HC-C3 位序规则产生的第 1 位，另一方作并列发现/同缺陷类显形（HC-C3⑦）。边界：对放大量级/增益环节的让渡（"种子如何放大归机制层"）不触发——只要该簇解释了主项起源与方向；触发判据是机制层语义，不是数值量级比较。②**覆盖外机制的生产者锚点**：机制定位在 dump 覆盖外（器件级/内核级/驱动/环境状态类）的候选承主语须同时满足：覆盖内证据链不依赖受污染捕获评得的[已证实]环节（HC-D5）；覆盖内存在**生产者身份锚点**——差异制造算子：其输入操作数（或参数）两侧一致而输出两侧分歧，或其操作数/参数被单侧替换，即差异在其处**进入**证据链。仅承载已发生差异的显形节点（输入已含差异、输出随之放大/传播）不得充当生产者锚点，须沿输入侧上溯至分歧进入点重新锚定（自证："该锚点节点的输入两侧是否一致"）。不满足时主语由覆盖内证据闭合的未排除非背景簇承载，覆盖外机制作为该簇因果链的机制层[待验证]环节并入。③现象量级悬殊本身不产生主语资格。

**HC-C3 位序规则**
- 触发：候选排序。
- 程序：①**覆盖内优先**：覆盖内未经有效域排除的结构分歧簇（含控制类操作数差异）位序高于任何机制环节在 dump 覆盖之外的候选——即使覆盖外候选自称有覆盖内指纹锚定（指纹相容 ≠ 指纹专属；须先完成两种解释的对比检验）。②**最早显形锁定**：全窗口执行序（forward 与 backward 槽位按 order 合并的全序；不得按现象类型把研判路径收窄到单侧执行序）中最早显形、未被有效域排除、且非背景级入口假设的结构/数值分歧簇，排在所有显形晚于它的候选之前。让位仅限 HC-C6 各情形。"算术闭合更完整""机制层推断更少"不构成让位理由——闭合义务约束伪影判定，不是跨候选排序准则。③**量级不参与位序**：候选间量级对比（差异比率/悬殊倍数/覆盖面/贡献占比）不得用于推翻或重排序锁定；量级只进入证据强度与置信度评级。④多个覆盖外候选之间按覆盖内指纹锚定排序：有指纹锚定者排在无任何指纹归属的配置类假设（freeze/requires_grad/zero_grad/优化器注册/梯度状态管理等）之前。⑤位序与主语资格只能被 HC-C3 本条或 HC-C6 各情形改变；"算术闭合不可判别/无法闭合""无法定侧/说不出哪侧错"均不是让位情形（闭合是排除与伪影判定的义务，不是候选资格的前提）。⑥**生产者锚点完备性位序后果**：差异制造算子未被捕获的候选——其机制主张的差异产生点（HC-C2② 形态）未被任何捕获节点承载，只能以差异的下游显形/症状簇（巨值、爆炸、塌缩等）承名、机制层整体[待验证]——不得位居同时满足以下两条件的其他未排除非背景候选之上：(a) 满足 HC-C2② 生产者锚点；(b) 已在该锚点节点完成任一节点级验证（消费点验证/算术闭合/守恒恒等式/写-消费三值核查）。症状簇候选"解释现象主项量级"的能力不构成位序或主语依据（只进证据强度/置信度语境）；其承重前提含 HC-D5 降级的"调用间一致/同输入"叙事时另受 HC-D5 位序后果约束。无满足 (a)(b) 的竞争候选时，症状簇候选可正常占位（如实标注机制层[待验证]）。**覆盖外锚定形态澄清**：候选的锚定节点为现象载体/聚合输入的消费节点，而其机制主张的差异产生点在覆盖外（未捕获的生产/写入/累积路径）时，即属本款"差异制造算子未被捕获的候选"——无论谓语表述为机制假说（生产路径/收集体行为差）还是状态断言（缓冲内容差），一律按本款定序，机制层 [待验证]如实标注；"差异制造算子未被捕获"以候选自报或生产反查证实（反查 0 命中/形状不相交）为准。⑦**同缺陷类归一审查**：同一侧存在多个单侧缺陷、且其机制指纹同属一缺陷类（就地写-消费断连/缓冲时序、单侧内容替换、守恒违反、数值实现差、表示类操作数差等）时，排序前必须完成归一判定并在候选资格表/报告留痕：它们是同一底层缺陷的多显形，还是独立缺陷？判定材料：机制类是否相同、同侧性、各显形模式能否由同一机制解释、时间与复现关系。能归一时，以**已捕获且已验证的显形**承根因主语锚点（该缺陷类最早显形 order 计位序），其余显形并入其机制层[待验证]并列报告；不能归一或无法判定时，如实按独立候选排序（位序仍依本条②/⑥）。禁止仅凭"同侧/同为数值差"跨类归一。⑧**差异源与放大器的位序纪律**：候选按机制角色分两类——**差异源**（满足 HC-C2② 生产者锚点形态的制造节点；或全实例同型、有侧别对应的覆盖内结构/内容分歧簇，含控制类操作数形态差与参数/常量派生槽内容差）；**放大器**（锚定节点输入已含 ≥1e-3 分歧、以本地增益/逐层放大承报的传播机制候选）。放大器候选与未排除差异源候选竞争位序时，**差异源优先**：放大器不得位居任何未排除差异源之上承根因主语，只能并入差异源因果链的传播/放大环节（并入方向依 HC-C7）；仅当全部在册差异源均已以各自本节点证据排除/判别闭合时，放大器方可承主语。理由：放大器放大的是已存在的分歧——以放大器承主语回答的是"为何悬殊"而非"分歧从何进入"，后者才是根因的机制语义（HC-C2 资格本义）；链路验证完整度不构成放大器对差异源的位序依据。⑨**同口径核验**：候选池内不同候选的资格核验与"独立根因"验证要求须同一口径——不得对拟落选候选（尤其结构/内容分歧簇）施加高于位序第 1 候选的验证标准（例如要求其"机制后果直接验证"方入优先组，而允许传播/覆盖外链候选携带同等未验证环节承报）。核验口径的候选间差异必须在资格表留痕并给出候选类别依据；无类别依据的口径差异视为不对称标准，相关排序无效、按本条②/⑧重排。**执行成本边界**：程序五各步与候选资格表填写同趟完成（角色标注即资格表"机制角色"列的产出、源优先重排即位序排列本身、同口径核对即资格表"锚点节点级验证"列与归一判定列的核对）——不设独立复核阶段、不重复通排已排候选；同口径逐一核对仅对验证类型不同的候选对执行，同类型候选默认同口径（在归一判定列留痕即视为已核对）。

**HC-C4 背景级判定**
- 触发：考虑把某差异判为"背景级入口假设"（数据/环境差异，位序让渡）。
- 程序：按**引入点与单侧机制语义**判定，不按覆盖内是否存在观测节点判定：差异的引入环节在 dump 覆盖外（数据加载/样本选择/环境配置）、且两侧各自行为无单侧机制语义（说不出哪一侧错、错在什么机制）的**输入类差异**（输入文件/图像/音频/随机流/数据分布），属背景级入口差异——其在覆盖内的首观测节点（如 permute/reshape 的 shape 分歧）不使其成为覆盖内结构簇；其"独立充分性"（"不同输入必然不同输出"）对一切输入类差异恒真、无判别力，不得作为位序提升或根因主语依据。
- **参数与模型状态不属背景级**：权重/偏置/checkpoint 加载结果/缓冲内容等两侧同名同位置的内容差不属背景级——它是单侧缺陷候选（一侧内容偏离共同来源），即使引入环节（加载/转换）在覆盖外、即使说不出哪侧错："无法定侧"只降低置信度，不构成让位，不得据此降位、排除或剥夺位序资格；单侧结构性指纹（仅某类参数出现 ≥1e-3 差异、方向恒定、其余参数逐位一致）必须作为定侧论证证据纳入。
- **表示类操作数守卫**：本守卫仅适用于覆盖内代码路径构造的表示类操作数簇（如 attention mask 的 dtype/极性/加性与反相表示差异）。援引背景级豁免前，必须核对该簇覆盖内**消费点**上是否已显 ≥1e-3 显著分歧且现象单侧不对称无其他已证实生产者——两者同时成立时不得判背景级：该簇保留为合格未排除候选参与位序（引入环节在覆盖外只作覆盖外归属标注）。适用硬边界：**输入类差异**一律不适用本守卫（随机流/样本选择的分支后果在覆盖内显形不改变其输入类归属）；**循环性禁令**："无其他已证实生产者"要件的判定不得依赖本守卫对当前簇自身的裁决结果（如两候选的生产者地位互为对方的否定论据）——此时该要件视为不可满足证据。"两侧均为合法表示"（合法性）与"该差异是否因果"（因果性）正交，不构成让位判据。

**HC-C5 排除迁移禁令与有效域**
- 触发：出现现象载体在捕获窗口外的机械指纹——摘要「⚠ 排除迁移禁令」警告（梯度覆盖缺口非空；聚合输入单侧悬殊且无窗口内生产者命中），或分析中已证实被验证路径输出与现象量级脱节、现象来自未捕获分支。
- 程序：①此前对被捕获路径上一切结构簇的"已排除/非因果"结论自动降级为"已核查（有效域=被验证路径）；对现象载体路径未排除"，不得再以"非因果"标注；②该簇必须进入候选排序——作为每个覆盖外根因候选的**机制层候选**（明确回答"该簇能否解释覆盖外行为/聚合输入的单侧不对称"；机制层连接判据是作用域/指纹的定向一致，量级比较不构成对连接的否定），或作为独立未排除候选（位序仍受 HC-C3①约束）；③豁免不可迁移，否定同样不可迁移：对覆盖内簇的机制连接否定必须给出现象载体路径上的可观测证据，覆盖外无观测即无否定资格；④消费点验证结论只覆盖被验证的那条执行路径——现象量不经由被验证路径（其输出近零/与现象量级脱节；现象来自窗口外分支）时，对被验证路径的等价结论不得迁移到该簇在现象载体路径上的行为；⑤单步窗口时间先序禁令：dump 窗口是单步执行序，"载体内容先于窗口存在/窗口进入时刻必已有 X"类跨步外推不得用于排除窗口内未排除簇——窗口进入时刻的载体状态本身可能是覆盖外机制与窗口内簇共同作用的产物；⑥**连接性否定断言的有效域**："与现象载体无连接/无机制通道"类否定，其论证证据的覆盖范围必须包含现象载体路径上全部未排除环节——含跨步（历史步累积/残留）与未捕获写入路径；仅由本步窗口内量级不可达或算术闭合支撑时，只能落为"本步捕获路径内未观测到连接"（[未验证]），不得写成"无连接/无通道"，不得据此降位、降置信度或降"作为根因"评级。覆盖外状态候选存在（载体输入侧异常状态的生产者未定位）时，对覆盖内簇的一切连接否定一律按本条降级处理。⑦**排序时点操作化——迁移核对**：统一排序落盘前（与 mechanism §3.9 程序五同趟，受 HC-C3⑨ 执行成本边界约束）执行**迁移核对**——梯度覆盖缺口锚点非空、或聚合输入单侧悬殊且无窗口内生产者命中、或摘要「⚠ 排除迁移禁令」横幅在册，三者任一成立时，候选资格表中一切覆盖内结构簇（dtype/控制类操作数/形状簇）及内容分歧簇的"已排除/非因果"状态逐簇改判为"未排除（HC-C5 迁移）"，原排除论据保留为"有效域=被验证路径"的核查记录（输入类差异按 HC-C4 硬边界不适用本核对）；改判是表格重写与标注，不要求重新验证；改判后按程序②以机制层候选参与排序。**压缩恢复后本核对以 investigation.json 的 anchor_checklist/覆盖缺口记录为准执行，不依赖重读摘要全文。**
- 后果：排除验证程序执行到位 ≠ 排除结论可迁移；引用有效域条款而不执行其后果，与未核查同罪。

**HC-C6 让位情形（四情形）**：候选让位（位序/主语资格变更）仅限：①有效域排除（消费点验证非因果，且满足 HC-B6③ 窗口闭合前提）；②背景级豁免（HC-C4 判定成立）；③并入更高位候选的机制层；④**机制形态不兼容让渡**：判据与形态对照要求见 HC-C2①（唯一权威定义处）；数值量级占比比较、量值界推论、"验证更强/闭合更完整"比较一律不构成让渡依据。④的防线：差异制造算子未被捕获的症状簇候选不得经④获得对已验证生产者锚点候选（HC-C3⑥ (a)(b)）的位序优势——症状簇自身机制层[待验证]，其"对方无法产生主项形态"的主张同样未经锚点验证，不能据以让渡已验证锚点候选。机制层环节在覆盖外时按 HC-C3①处理，位次不因此低于显形更晚的候选。

**HC-C7 并入方向固定**："并入不转移根因身份"的合并方向固定：并入操作的宾语 = 位序更高/证据更强的簇；[已证实]事实簇（内容差/结构指纹/守恒违反等 dump 可查事实）不得被降格为[合理推断]叙事簇的"并列事实"或"机制层"。根因链由覆盖内指纹簇与覆盖外环节共同构成时（无论该簇独立占位还是已并入其他候选），根因表述必须以**覆盖内指纹簇**为主语（覆盖外环节作为其机制层/传播路径如实标注待验证状态）；禁止反转为"覆盖外生产路径/状态不对称"作主语、把指纹簇降为其机制层候选——覆盖外环节是现象生产位置的复述（载体定位的延伸），不是数据内可命名的因果实体。根因主语移交覆盖外候选的唯一条件：该指纹簇已被有效域排除，或数据内不存在任何覆盖内未排除指纹（如实报告"根因只能定位到覆盖外"，不得虚构指纹）。**通道假说呈报义务**：两者并呈时（覆盖内指纹簇承主语 + 覆盖外状态/写入路径定位），报告必须为"指纹簇 → 覆盖外状态差"给出至少一个机制可达的通道假说[待验证]（跨步累积/早期步残留/未捕获同步写入路径等；通道假说不要求量级闭合——HC-D7①/HC-E2 末款），呈报于主语候选因果链的机制层；未呈报任何通道假说而仅断言"无连接"的，按主语让渡违规处理（本条禁止的反转已发生）。

**HC-C8 候选资格表与三级一致性**
- 触发：候选清单落定前、报告结论落笔前。
- 程序：①候选清单行落定前，先在盘上落**候选资格表**，每候选一行、逐格填写：`锚定节点 | 谓语改写测试（改写为"载体（或其输入缓冲）X"句式后语义是否不变：不变=失格）| 锚点验证（正向生产者锚点节点名（或"无"，附"该节点输入两侧是否一致"自证）；节点级验证：消费点验证/算术闭合/守恒恒等式/写-消费三值核查/**结构分歧实证（仅限结构分歧簇与控制类操作数簇——双侧锚点槽位直接核验分歧本体并两侧并列：dtype/shape/极性/取值模式/构造链差异；该类候选主张的差异制造环节=操作数形态差本身，其消费点行为验证（HC-D1）是维持未排除的持续义务，不是入优先组的额外门槛）**之一=已验证，注明类型；否则=未验证；**验证对象须为候选主张的机制/差异制造环节，载体值复现不算**；同缺陷类归一判定（组名或"无同类"）| 背景级与未排除（含 HC-C5 迁移改判留痕）| 资格结论（含机制覆盖内/外）`。**落盘位置**：逐候选存 evidence.json `candidates[].qualification`（四格同名键：predicate_rewrite_test / anchor_verification / background_unexcluded / verdict；引入 order 与机制覆盖内/外不设格——前者 node 字段含调用号+order，后者并入资格结论格），报告 §3 只誊总表、不誊资格表。资格=通过谓语改写测试 ∧ HC-C2 ∧ 非背景级 ∧ 未排除。**排序第 1 位产生规则**：资格通过候选先经 HC-C3⑦ 归一审查（归一判定留痕于锚点验证格），再按两级分组——优先组=满足 HC-C2② 生产者锚点且锚点节点级验证=已验证的候选（含归一后承锚点的显形），组内 order 最小者居第 1 位；**优先组资格核验**："锚点节点级验证=已验证"的验证对象必须是候选主张的机制/差异制造环节（该锚点上"输入一致而输出分歧"、操作数被单侧替换、守恒恒等式违反、写-消费断连等之一）；**载体值复现与聚合输入值/现象值的数值核对属载体证据（HC-C1①），不构成锚点节点级验证**——凭状态值闭合入优先组无效；**发射/放大/传播环节的验证（发射实值枚举、链增益剖面、放大链算术闭合——即 HC-C3⑧ 放大器形态：锚点节点输入已含分歧）属传播环节证据，同样不构成机制/差异制造环节验证、不据此入优先组**；无生产者锚点的覆盖外状态候选（HC-C2② 不满足）不入优先组；HC-C1②③ 失格（载体状态复述）的候选不进入排序。优先组为空时，其余候选按 order 最小居第 1 位（症状簇/锚点未验证候选承位时如实标注机制层[待验证]，其量级解释力只进置信度语境——HC-C3⑥）。报告主候选与根因表述必须与表一致，不一致即重写。禁止跳过填表直接叙述排序。②**三级一致性**：报告根因表述第一条主语=候选资格表位序第 1 合格候选（头号根因候选）；裁定主语与第一条主语同主语；禁止把根因交给资格表自判{资格拒绝/背景级/不占位序}的任何簇（含"现象复现/载体槽位分解/现象值精确映射"类换皮条目）——后者只能作第二条起的并列发现或边界声明。③**回退呈报**（位序第 1 簇经 HC-C2① 判定不能承主语、且无其他覆盖内簇可承时）：根因表述第一位以该位序第 1 簇为"头号根因候选"（HC-C2① 边界声明照写，不因升级而删），覆盖外主项定位降为并列发现居第二位；禁止把不可捕获、[待验证]的覆盖外机制写成高于窗口内已证实结构性差异的第一位。落盘前三问（任一"否"必须改写后再落盘）：第一条主语=资格表第 1？裁定主语=第一条主语？裁定主语不属资格拒绝/背景级/不占位序集合？

**HC-C9 执行侧叙事准入闸**
- 触发：候选以执行侧差异（并行分解/归约顺序/内核精度路径/调度等非内容性机制叙事）承根因主语或居于其他未排除簇之上。
- 程序：其锚定节点必须满足**全部输入操作数两侧逐位一致或 rel<1e-3**（近一致；自证逐输入列出并如实标注不一致项）。任一输入存在 ≥1e-3 内容差而该差未被并入本簇机制层时：①该节点不满足 HC-C2② 生产者定义（"输入一致而输出分歧"前提被自身输入差否定）；②执行侧叙事簇不得居于承载该内容差的簇之上，只能作为该内容差簇因果链的机制层[待验证]环节并入（并入方向依 HC-C7）。对称适用于覆盖外叙事簇：覆盖外机制无正向锚点时不得居于有 [已证实]内容差事实的簇之上——锚点缺失对两类簇一视同仁。

**HC-C10 量级界与窗口级量词**
- 触发：①任何候选以"量级界/连接断裂"类主张（例："窗口内反向值全部 ≤X，无法生产载体的 O(Y) 内容"）支撑让渡、降位、排除或"与主项无因果连接"判定，或据此把主项起源定位到覆盖外；②任何窗口级量化量词陈述（"窗口内全部 X≤Y""全窗不存在 Z"）。
- 程序：①**量级界不构成让渡依据**："机制形态不兼容"仅指机制形态层面对照（双侧对称制造无法产生单侧不对称、生产-消费关系不成立、作用域不相交等），**不包括任何数值量级对比或量值界推论**——"窗口内值 ≤X 而载体需 O(Y)"属量级论证，经 HC-C6④ 让渡无效。窗口内已验证差异源簇与聚合输入单侧悬殊主项（现象载体输入无窗口内生产者/主项量级跳变等）之间的连接判定，只能以 **HC-C7 通道假说形态呈报**：该簇承 rank-1 头号根因候选（边界声明照写不删），载体抵达/跨步环节如实标注[待验证]；禁止以量级界宣布"连接断裂"、把主项起源让渡覆盖外、或把该簇改写为"与主项无因果连接"。②**窗口级量词必须全数清点**：窗口级量词陈述的口径声明=清点 rank 数×槽位集范围×谓词阈值，且该集合必须经 census 类全量取数在**全部 rank/全部可比槽**上闭合（枚举闭包，非抽查）；以单 rank 或局部槽集算得的界外推为窗口级量词=事实错误，其支撑的一切主张（断裂/让渡/排除）一并作废。③量级事实本身可入证据强度/置信度语境，但不得承任何位序/资格/让渡论证（HC-C3③ 纪律延伸到连接判定）。

**HC-C11 验证深度与位序挂钩**
- 触发：阶段四候选详析的证据取数与闭合深度分配。
- 程序：①**全体候选以承报级为验证基线**（位序第 1 亦然：锚点槽位直接核验+折叠普查+代表槽对照；其主张所涉窗口级量词的 census 义务不减——HC-C10②/HC-B8 不因此减免，census 按⑥折叠口径执行）；充分闭合级验证（全量逐实例枚举、逐 rank 展开、深闭合证据）在 L3 触发条件下按②轮候执行，完成当前决策所需后立即停止。②**深挖轮候（位序定顺序、盒定总量，不定资格）**：所有候选走同一条升级通道——承报级基线完成后，L3 触发条件成立的候选按**位序顺次**升级深挖：位序 1 先行，其深挖阶段结束（闭合完成、判定当前数据无法进一步闭合、或盒冻结）即轮到下一位；盒内无余量则轮候终止，未升级候选按承报级形态如实承报（HC-D2 承报级最小充分集=锚点四统计量并列+方向/形态普查一遍+代表槽对照，按 HC-C7 通道假说/[待验证]形态承报，不因深挖缺失而降位或删除）。轮候到位的深挖同样受「完成当前决策所需后立即停止」约束——为深挖而深挖仍属过度分析。③**承重甄别豁免**：保护 rank-1 证据可靠性所必需的前置甄别不属次候选深挖、义务不减——对齐/错位排除（假巨差行甄别）、捕获伪影排除（HC-D3/D5）、rank-1 主张所涉 census 义务、以及用于支撑 rank-1 位序判定的竞争候选 HC-D1 消费点验证。④位序挂钩不改变命中判定义务与让渡纪律：rank-1 闭合失败需位序调整时仍按 HC-C5/C6 口径的量级界/统计量禁止外推为窗口级闭合——用 `query.py census <rank目录父路径> --backward`（一次调用枚举全部 rank 全部 .backward 输出 Norm）或 `--patterns`（一次调用全 rank×全匹配节点×全槽位）闭合，禁止逐 rank 交互取数拼凑。(c) **控制类操作数结构簇的位序保护**：mask/索引/条件/scale 候选属**分歧表现类**（自身制造归因未闭合——**不论其成因枚举是否显式列出该结构簇：成因清单未穷举或未衔接在册分歧源簇时同样触发**）时，该结构分歧簇承**位序 1 或并列位序 1**，到反向载体的通道按 HC-C7 [待验证]附报——**分歧表现本身不得在成因候选未闭合时独承根因主语**；③本条款不改变 HC-C6④ 形态对照让渡与 HC-D1 消费点验证义务的适用。⑥**普查折叠与批量亲和（承报级普查的统一执行口径）**：候选承报所需的「方向/形态批量普查」=族级批量调用一次（`params`/`census --patterns`/`survey` 单次覆盖全库参数槽/全 rank×全槽位/全窗口同名对——**发现层覆盖面不得折叠省略**，折叠只发生在实例确认层）+代表实例抽样确认（每族 ≤3 个代表实例；多 rank 布局抽 1-2 **HC-C12 状态型内容差簇与实现型制造差簇的位序正典**
- 触发：候选池并存两类已验证差异源，且二者对现象载体的贡献在当前数据口径下不可分解（statistics 级数据无法逐位分离各自份额）——(A) **状态型内容差簇**：参数/输入槽内容差，方向系统性单一（逐槽同向占比 ≥90%）且极值形态恒等（Max/Min 跨槽一致或逐位同形），产生环节在窗口前/覆盖外，窗口内已有传播或夹逼/恒等式闭合；(B) **实现型制造差簇**：算子内部数值实现差（制造锚点=输入一致而输出分歧），逐槽无方向性散布。
- 位序后果：① (A) 位序优先于 (B)，(B) 至多并列/背景级承报；② (B) 的验证状态上限=制造环节本身——其到载体的"累积放大/平台归因"类主张属推断环节，**终态上限=较强候选，不得单承"已验证根因"主语**（推断环节不撑已验证终态，HC-E）；③ (A) 的窗口内传播/夹逼/恒等式闭合核算**视为计算效应已验证**，禁止以"贡献占比未分解"为由标注"真实计算效应未验证"并据以降位——"不可分解"对两类候选对称，不构成对 (A) 的单方面举证加压（HC-C3⑨ 同口径）；④ 仅当 (A) 被以不低于 (B) 的证据强度排除对载体的贡献时，(B) 方可承根因主语；⑤本条不改变 HC-C3②⑧ 与 HC-C6 的适用。

## HC-D 验证义务

**HC-D1 消费点验证**
- 触发：对 dtype/值域/极性等**结构分歧簇**或**控制类操作数**（mask/索引/条件/scale——决定"算不算、算多少"）做"语义等价/非因果"结案。
- 程序：结构分歧簇必须逐条研判留痕，不得合并进"背景差异/适配实现"叙事一揽子豁免。"语义等价"结论必须在**消费点**验证：①找到接收该操作数的算子；②对比该算子**前向**输出行为；③对比该算子**反向**（或下游梯度）行为。仅证前向等价不构成豁免——反向行为可能不同（控制操作数常改变反向分派路径）；前向、反向任一环节未完成验证，该簇即为"未排除候选"（前向已验、反向客观不可验，仍属未完成）。消费点上的首次 ≥1e-3 分歧是该簇下游影响的实证起点，必须计入该簇证据，不得表述为"前向可比"；也不得以"量级不足以解释最终差异"降权——除非给出后续链路增益有界的具体论证（长链非线性网络中，小幅种子沿残差/深层链放大到量级差异是常态）。
- **反向对比封闭性**：放弃反向数值对比的裁定只适用于已证实形状或语义错配的具体族（逐族给出错配证据）；禁止外推为全局裁定；两侧形状一致的反向节点必须纳入对比。控制类操作数簇的任何"已排除"结论，若其消费点验证只覆盖前向而簇内算子的反向已捕获未对比，排除无效。宣称"该簇全部消费点已验证/无 .grad 写入路径"前，必须核对簇内算子反向的捕获与对比状态。
- **结构组成分歧簇**：直接证据仅为形状/槽位组成/调用序列组成（无消费点数值行为验证）的候选，占据排序第 1 位前必须完成至少一个消费点的数值验证，或给出到现象载体的参数级映射闭合。
- **终端完整性**：现象公式（loss/gnorm 计算式）未捕获、dump 内存在多个已捕获的"预测/输出空间"终端且各终端分歧状态不同时，任何"非因果/贡献恒零"的排除不得只论证其中一个终端——任一同形状终端存在未被有效归因的显著分歧，即足以维持该簇未排除。两侧同形状的全形状 Module 节点是可靠对比对象，不因"分片激活合并语义未证实"例外豁免（该例外只覆盖两侧形状不同的分片统计）。

**HC-D2 算术闭合**
- 触发：把高置信锚点或关键槽位判为"捕获陈旧/统计伪影（非因果）"；或主张"闭合不可判别/无法闭合"并据此降位。
- 程序：①判伪影前必须给出能**同时解释相关全部捕获槽位（含消费节点的输出统计）**的替代失真机制——只解释输入侧的陈旧叙事不完整；②对至少一个可判别的算术恒等式完成闭合（例：逐元素加法 mean(out)=mean(A)+mean(B)、Max(out) ∈ [A.Max+B.Min, A.Max+B.Max]；输出四元组与"正确语义产物"四元组是否可分）；③失真机制**逐槽**给出，禁止由个别槽位失真外推"整链语义正确"。闭合失败或未执行时，锚点保持根因直接证据地位，不得标"非因果"。④**输出侧双假设闭合**：主张"闭合不可判别"前，先做消费节点输出侧双假设闭合——按"该操作数=语义应然者"与"=实测捕获者"分别预测消费输出统计，与实测比对：何者闭合即判别何者真实参与运算；输入侧生产者未捕获只阻断输入侧溯源，不阻断输出侧闭合。未做输出侧闭合即断言"无法闭合"视为违规。⑤**身份命中的语义结案**：操作数身份命中（四元组反查命中生产者）只证明捕获自洽，不证明语义正确；两侧操作数四元组不可公度（分布/量级/dtype 来源显著不同）且该槽位两侧语义应相同时，即为**单侧语义缺陷候选**（传错张量/错误求和项/错误缓冲），保持候选证据地位进入排序，不得以"命中=合法自身同一性"结案。**公度性判据与生产链闭合效力边界**：①不可公度的判定覆盖**全部四统计量与取值模式**——极值/取值模式结构性不同（精确钳位或离散取值 vs 连续大值、符号模式不同、取值集合不同）即属分布形态显著不同，**Norm/Mean 接近不构成公度证明**；②"生产链闭合"（写入值→消费值捕获一致、身份指纹命中）只闭合**身份**（未传错张量），不闭合**内容正确**（写入/驻留内容=该槽语义应然内容）——被写内容本体与对侧同槽呈①的结构性形态分歧时，本款照常触发；③把该分歧归因于背景级差异源（输入样本/配置差）的，须给出该背景源到该槽的演化路径与幅度核算（背景源可解释的幅度上限 vs 实测分歧幅度），且受 HC-D12② 约束（参数/常量派生张量不适用输入类豁免）；核算不闭合的归因无效，槽位保持单侧语义缺陷候选。**前向闭合效力边界**：loss/前向算术闭合（损失节点双侧一致、前向传播路标一致）只闭合**前向效应域**——证明分歧未改变本步前向计算/损失值；对机制主张在**反向域**的候选（反向行为差/梯度流差/反向分派差/梯度生产差），前向闭合不构成排除或降位证据——反向域候选的排除须反向域证据（反向闭合/反向守恒/反向分派判别，如控制操作数对反向 kernel 选择的影响），并受 HC-C5 排除迁移约束（窗口内路径缺席不可外推）。前向闭合与反向分歧并存不矛盾：分歧种子可逐位一致而分歧在反向网络内制造。⑥**参数/常量槽位双假设纪律**：
  - 触发：参数/权重/偏置/常量表槽位（或候选锚定节点的输入操作数槽）呈"Max/Min 双侧逐位一致而 Mean/Norm 分歧（≥1e-3）"形态，且分析欲将其归类为捕获伪影、据此排除"参数携带误差"通道、或在反证中写"参数内容差已排除"。
  - 程序：①Max/Min 恒等仅证明极值元素取值一致；"精确统计恒等"（内容一致）要求四元组全等——两条恒等不构成内容一致的证明。②该形态与两类假说均相容：H-artifact（单侧捕获 Mean/Norm 归约失真）与 H-content（参数存在非极值元素级真实扰动——正是"参数携带误差"通道的数据形态）。③该槽位属于根因候选主张的差异制造节点（或其锚定链节点）的输入操作数/parameters 槽时：H-content 必须作为并列机制假说呈报[未排除/待验证]（两侧四统计量并列给出）；把 H-content 写成"已排除"需要**不相容证据**（证明该形态与内容扰动原理上不可共存），仅形态学相容性证据（方向恒定/幅值反相关/网格量化）只支持 H-artifact，不构成对 H-content 的排除。
    ④反证条目"参数/checkpoint 内容差：已排除"受本条约束：依据不足时改写为"未排除（伪影假说与内容扰动假说并存，形态学支持前者但无判别力）"。
    ⑤判别手段的**有效域约束**：程序二第 3 条的判别（查同参数其余捕获点、对消费节点做输出侧双假设闭合）只对**采证节点自身**的假说有效——把判别结论推广到其他节点受 HC-D2⑦ 约束。
⑦**闭合有效域与跨节点泛化禁令**：
  - 触发：以某节点上的闭合证据（输出侧双假设闭合/伪影闭合/算术闭合）支持、排除或降权**另一个节点**上的假说——典型句式"同理""同簇同判""姊妹节点已闭合故本节点同判"。
  - 程序：①**闭合有效域=采证节点本身**。把闭合结论推广到其他节点前，必须核对目标节点**独立满足该闭合的前提条件**（尤其"输出统计一致"类前提——目标节点输出统计分歧时前提不成立，禁止同判）；前提核验引目标节点自身的输入/输出槽对照值，一节即足。②**输出分歧节点的唯一在册差异源承报义务**：节点输入逐位一致而输出统计分歧时，该节点上分歧≥显著阈值的操作数槽（parameters/常量槽）是其唯一在册差异源——对应的 H-content（参数/内容差）必须保持承报（候选身份或双假设并列），除非以**该节点自身证据**完成判别闭合；凭姊妹节点闭合泛化排除即违规，相关通道恢复候选/双假设地位。③**算子实现差机制的同族一致性核查**：主张"算子实现差在相同输入上制造分歧"类机制时，必须核查同族同精度、输入逐位一致的兄弟实例的显形形态（`query.py diff`/`gain` 同族 patterns 逐实例 r_in/r_out）——若存在输入一致而输出不显形的兄弟实例，该机制无法解释显形/不显形的分布，报告必须如实对照此不对称，且须并列呈报能同时解释两形态的替代机制（如差异源仅存在于显形节点的参数内容差）[未排除]；只呈报单一机制且不对照兄弟实例形态即违规。
  - 违反后果：跨节点泛化的排除/降权判定无效；报告按"关键通道遗漏/主语错位"在评审中计。

**HC-D3 守恒检验**
- 触发：归约/复制/广播类算子（repeat_interleave/expand/sum/mean 等）出现分歧；gnorm 现象分析。
- 程序：凡可检验数学不变量的算子（归约求和、复制/展开、线性、逐元素恒等）都应**分侧执行、分侧给结论**（如 mean(out) ≟ N·mean(in)）：**违反不变量的一侧是缺陷侧第一指向**（该侧归约实现/精度不足，或该侧捕获不忠实——同位置）；"某侧数值系统性偏大/偏小"的方向性指纹本身不构成侧别归因（偏大方可能只是对侧违反不变量的镜像）。mean 级检验只需 Mean 统计量即可分侧计算；**不得以"无法逐元素复核"为由跳过分侧结论**。mean 类反向的语义性"违反"两侧应同样违反；组距不均两侧同违反；bf16 网格给 N_eff ~0.4% 级模糊。②**守恒不变量过滤器与逐实例甄别**：一侧满足恒等式而另一侧违反 → 节点级甄别——区分"读数不忠实（捕获层伪影，归伪影簇，不承根因）"与"读数忠实、短缺/增益为真实行为（归根因簇）"；甄别须给出三重锚定之一（逐元素确定性输入 + 消费链 producer=consumer 一致 + 参数/下游算术闭合）。同族任一实例被证伪不得推及全族——禁止以族为单位整体采信或整体弃用。"上方违反"（N_eff 超复制倍数等"忠实求和不可能"形态）优先判捕获层伪影；下方/双向偏离须逐实例三重锚定后方可定性为真实行为。

**HC-D4 写-消费三值核查**
- 触发：窗口内存在**就地写算子**（`__setitem__`/`add_`/`mul_`/`copy_`/`fill_`/`masked_fill_` 等写语义 API），且同侧存在对同一缓冲（按 shape+dtype+ 统计量匹配或数据流可判定）的后续读/消费节点。**触发信号扩展**：'身份不对称/四元组反查/张量同一性指纹'类锚点的四元组在同侧命中任何写语义 API 的输入/值槽（写节点槽位出现同一四元组），**本身就是本条触发信号**——该锚点结案前自动进入本条程序，不以分析者是否将其登记为"就地写候选"为前提；"生产链归属已判明"（如判明命中=某缓冲自身的转换链/路径）不构成跳过理由。**取数方式注记**：三值核查取数=反查已识别槽位的直接 node/quad 读取（写前=写节点输入槽、写入值=写节点值槽、消费值=消费节点对应输入槽）+ 一个算术恒等式闭合（如输出 Mean=in1+in2），**禁止为此新开扫描或逐实例枚举**——该核查的历史形态即 2~4 次槽位直读。
- 程序：**逐侧**执行三值核查：①该侧写节点的输入（写前内容）；②该侧写语义上应产生的内容（写后推定）；③该侧消费节点实际读到的内容（消费值）。若某侧**消费值逐位等于写前内容而非写后内容**，即构成**写-消费断连**，为一等根因候选（位序按写节点计），并在结论承名。
- 后果：禁止以下列任一理由跳过或结案该核查：①跨侧比对结果（无论一致或分歧）；②对侧自身一致性；③"合法自身同一性/背景级伴生"叙事；④存在数值更剧烈的其他分歧簇（爆炸簇不得占位挤出本检查——位序只按执行序，量级不参与位序）。任何对就地写锚点的结案（排除/降权/保留）留痕必须附**逐侧写前/写后/消费值三元组**；缺任一侧即结案无效。**归属断言核查深度**：对四元组命中作"X 缓冲自身的转换链/路径"类归属断言，必须至少上溯一跳核到该生产者的输入槽身份（生产者输入四统计量与更上游输出对照或身份反查），不得凭路径重合推断归属；同位 op 槽两侧张量的值域极值签名不同类（如一侧精确 ±1.0 归一化输入量程、另一侧参数/嵌入量程）时，两侧该槽为**不同张量流**——跨侧 NRE 不得作为参数/配置效应的数值证据，该槽分歧按结构/路径分歧归档（可比性）。**判读正典**：三值事实的判读按以下正典执行，禁止反读——①写目标缓冲的**写前内容签名 ≠ 该缓冲语义应有内容**（该槽语义角色应有量程/分布签名之外的内容类别）＝**缓冲顶替证据**，禁止以"四元组命中=同一张量流的正常同流身份"解读为正常——同流恰恰说明被消费缓冲不是语义应有的那份内容；②**写前=写后=消费三值全等且写入值槽（写节点的值输入槽）≠ 该 quad** ⇒ 写未生效（写入内容与落盘内容不同流）；③对侧同位写生效对照（写后值进入消费槽）是断连判定的独立旁证；跨侧签名不同类按可比性条款归档，不免除①②的逐侧判定。

**HC-D5 捕获证据资格**
- 触发：同一侧捕获层出现伪影证据——(i) 同一逻辑张量在不同槽位的读数不可公度（上游节点 output 与下游节点 input 统计矛盾，含 NaN∧有限并存）；(ii) 同族槽位存在语义错位指纹（错配族成员）；(iii) 链上单槽位 NaN 而相邻槽位有限。
- 程序：该侧"调用间/实例间捕获逐位一致"不得评为[已证实]的"输入/前提一致"证明（内存池/缓冲跨调用复用下，陈旧捕获可伪造一致性）；整条"同输入→异输出→单侧执行状态依赖"类推理降为[合理推断]，不得作为位序攀升或置信度评级的主要依据；含"全量小值/逐位一致"类否定性证明（"新鲜、未累积、未发生"类结论）。防滥用边界：捕获层无伪影证据的一侧不受限；本条不禁止把"捕获一致"登记为线索，只禁止评[已证实]并据以承主语或升位。
- **对称适用**：审查对象是**每个候选的证据链**（含排序第 1 者），而非伪影证据首次出现的那个候选——凡以本条排除、降级或拒绝资格任一候选时，必须**先于该排除**以同一标准审查位序第 1 候选的承重前提：第 1 候选若同样依赖被禁止的叙事（"调用间逐位一致→同输入"前提已被降[合理推断]），则同受排除或同步降级、位序由下一合格簇递补——禁止只杀一方。"该候选读数外部可观测/爆炸数值真实"不构成豁免：读数真实 ≠ 证据链未受污染。在支持候选处采信某侧读数、同时把该侧伪影证据仅用于打击其他候选，即先信后疑双重标准违规。
- **位序后果**："承重环节均为输出侧闭合证据"不构成对上一款的豁免：输出侧双假设闭合（HC-D2④）证明的是**数值真实存在与传播路径**，不证明**缺陷身份**（"损坏/单侧异常"归因，即区别于"输入本就不同"的判定）；缺陷身份归因依赖"调用间/实例间捕获一致→同输入"叙事、且该叙事已被本条降为[合理推断]的候选，不得占位序第 1、不得承根因主语（位序由下一合格候选递补，其作为并列发现如实报告）。交叉引用：HC-C3⑥ 对症状簇候选的位序约束以本条为依据之一。
- **伪影族处置默认形态**：单侧系统性捕获失真族（如成规模透传/不可公度族）的甄别=**族级单列**（整体登记为数据质量候选）+ **一次独立归约交叉排除**（独立 gnorm 估计/独立守恒口径等窗口内独立证据，证明其对根因链无干扰）——据此即可结案该族对根因链的隔离，**禁止对该族做逐实例甄别**；逐实例甄别仅在承重结论直接依赖该族个别实例的读数时，对被依赖实例触发。同族任一实例的"真实行为"定性仍按守恒甄别三重锚定执行（本条只约束"隔离伪影族"的成本形态，不降低定罪门槛）。
- **同张量两次捕获不一致对的处置**：同一逻辑张量更早捕获有限/正常、更晚捕获非有限/极值（或反之）的不一致对，当窗口内**已有捕获失真证据在册**（本条 (i)~(iii) 任一形态或已登记伪影族）时，一律按**捕获伪影类处置**（族级单列+附报），不得作为"执行级损坏/内存损坏"类运行时缺陷主张的定案主语——运行时损坏主张须有**独立于捕获统计的闭合证据**（损坏值被多个相互独立的下游消费点以算术自洽方式复现，或捕获外的可复核恒等式）方可承主语；窗口内无失真证据在册时按注入形态伪影优先序双假说并列。
- **注入形态槽位的伪影优先序**：某槽位呈"同张量更早捕获一致（或同内容多槽捕获一致）→本槽单侧突变为非有限/极值，且窗口内无任何捕获节点可产生该突变"的注入形态时：①捕获伪影为第一假说（与 HC-D3②"上方违反优先判捕获层伪影"同源），运行时机制假说须以独立于该槽自身的正向证据（下游多消费点自洽传播等）承报，两假说并列并如实标注判别缺口（窗口内不可判别时如实说明）；②该类簇与"输入侧在册内容缺陷候选"（HC-D2⑤ 单侧语义缺陷候选）竞争位序时，HC-C3②（最早显形）与 HC-C3⑧（差异源优先）照常适用——**HC-C6④ 形态对照的效力域=判别"某机制能否产生某显形"（通道判别），不构成跨簇位序依据**，不得以"某机制原理上无法产生本显形"把本类簇推到输入侧内容缺陷候选之上。

**HC-D6 否定性反查不构成锚点**
- 触发：以反查/搜索的**无命中**（"全库无生产者命中""N/N 未检出""窗口内缺失"）作为推理支点。
- 程序：无命中只确立"覆盖内未见生产者"这一[待验证]级事实；仅当该槽位类型的捕获完备性被独立证明（全量捕获声明+抽查一致）时才可升级为"产出发生在窗口外"的[已证实]。统计型 dump 的捕获槽位集合默认不完备（反向钩子仅单侧捕获等单侧捕获差是常态）——"封闭集"措辞仅可用于数学恒等式（如守恒检验的段和集合），禁止用于"捕获槽位集合"。凡以无命中升级置信度或位序者，须先声明捕获完备性证据；无证据则该支点降[待验证]。HC-C2② 的生产者锚点必须是**正向命中**（覆盖内某节点输出与候选证据张量逐位/公度命中）——反查无命中不满足。

**HC-D7 跨步外推禁令与封闭集枚举**
- 触发：排除"多步累积/历史步长/此前步骤状态"类替代解释；或作出"该簇的一切已捕获消费路径终点（位级一致/低于激活粒度）"类封闭集断言。
- 程序：①禁止以本窗口（本步）的梯度/流量/差异量级外推历史步的量级（本步量级本身是待解释项）；历史步量级窗口内不可观测时该替代解释保持[待验证]，不得标"排除"；只有窗口内存在对历史步量级的独立划界证据（每步守恒约束、配置常量、多步 dump）时方可排除。②封闭集断言必须附**显式节点名单**（枚举到节点名），名单覆盖该簇下游全部已捕获消费节点——包括预测/输出类 Module 节点（预测头、分类头、输出 Linear）与两侧同形状的 Tensor 终端链（含全形状聚合后节点）；名单遗漏任何一个已捕获下游节点即断言不成立，该簇保持未排除。

**HC-D8 生产者反查**
- 触发：对任何被引为"进入现象路径的分歧"的操作数/张量，断言"窗口内无其生产者/生产在覆盖外"。
- 程序：必须对**两侧**分别做输出四元组反查（同侧任一节点的 output 槽位四统计量与该操作数在统计网格容差内一致即命中，含 `_rankN` 副本；查询模式见 mechanism §3.6）；任一侧命中即推翻该断言，且必须把命中生产者的**输入操作数逐槽分解**、定位分歧从哪个操作数进入（沿生产者链继续反查，直至分歧进入点或覆盖边界）——禁止停留在"覆盖外重推导/单侧重推导"叙事而不分解窗口内可观测的输入。"窗口内无生产者"作为覆盖缺口事实陈述时，必须附反查留痕（搜索方式、容差、覆盖范围）。

**HC-D9 栈帧纪律**
- 触发：①锚定槽位呈单侧读数异常签名（任一侧 Max/Min/Mean/Norm 出现非有限值而另一侧有限；或同一侧读数与 shape/dtype 合法性明显矛盾）；②作出"两侧调用栈不同/分派路径不同/实现路径不同"类结论。
- 程序：①单侧读数异常簇的资格判定**之前**必须完成两侧 stack.json 的语义同一性核对：提取锚定节点两侧栈帧，比对执行语义上下文是否同 identity（同函数/同调用点语义，允许 NPU/CUDA 后缀差）。identity 判断必须基于两侧**叶帧**（调用点帧）逐帧回查比对，禁止取一侧 caller 帧与另一侧叶帧拼贴比较（两侧栈常共享深层 caller 帧）；引用栈帧文本时标注帧号。两侧叶帧语义同 identity → 异常读数判为捕获层伪影，该簇结案伪影、移出候选清单（位序递补）；不同 → 保持候选资格。②"路径不同"结论必须给出：两侧叶帧原文（stack.json 中 api_registry 之后的第一个帧）、逐帧对齐后的首个分叉帧及其前序全部同帧证据、栈组号与组内节点集引用。两侧叶帧同文件同行号时，"实现路径分歧"结论一律不得成立（可改述为版本/分支差异并附行号差与两侧安装路径证据）。③反护盾条款：凡按 HC-D5 被降为[待验证]读数、且其锚定证据全部依赖该侧读数的簇，不得通过资格判定、不得占位序第 1、不得承主语——"伪影闭合/算术闭合义务未了"不得作为保留其位序资格的依据；该簇只允许作现象侧旁证引用。

**HC-D10 反证数值核对与语义角色溯源**
- 触发：反证中作出"逐位一致/噪声级/无显著分歧"类断言；或反证链用于①侧别反转、②切断某簇与现象连接、③确立"本体一致/训练未发散"类全局断言。
- 程序：①"逐位一致/噪声级"断言必须给出实际比值（或相对差）与噪声地板数值；比值偏离 ≥2× 地板不得称"逐位一致"，偏离 ≥10× 不得称"噪声级"。引用真实数据但结论与数据形态相反的反证视为反证无效，被反证的簇保持原位序，且该反证不得再承担降位/切断功能。②语义角色判定：凡承担①②③的反证链，其关键节点的操作数必须完成同侧溯源（四元组命中）+ 语义角色判定（该张量是 .grad、参数、动量/EMA 还是其他状态——依据生产者身份与系数指纹；更新类循环 `mul_(s).add_(x, alpha=t)` 存在同构歧义：EMA 更新 x=参数本体 vs Adamexp_avg 更新 x=梯度的标量指纹完全相同，系数指纹对二者无判别力——此时必须引用**栈帧文本**定案，或给出操作数≡已捕获参数四元组的身份命中；禁止仅凭标量系数断言"此链消费梯度"）。dump 未捕获 parameters_grad 时，dump 内不存在 .grad 的直接标识，任何"此链消费梯度"的断言都必须给出生产者链证据。语义角色无法判定的反证降为[待验证]，不得承担①②③。断言链"消费 X"与窗口内"X 的消费不在窗口"类观测矛盾时，必须先调和矛盾再使用该链。

**HC-D11 首分歧归属语义**
- 触发：使用首分歧锚点做归因。
- 程序：前向/结构首分歧所在的结构分歧簇是"最早显形归属候选"。首分歧消费点之前的执行序已被证实逐位一致时，该消费点上的显形**不能归因于任何更早环节**——包括"窗口外参数/状态已分歧"类假设：此类归因必须给出该假设在窗口内的**可观测印记**（哪个被捕获槽位承载了它），无印记即无归因资格。首分歧之前所有匹配节点统计一致，只说明"dump 覆盖内更早处无显形"，不排除差异在覆盖外（输入数据、数据加载）已被引入——如实说明覆盖缺口。

**HC-D12 锚点操作数溯源（固定步骤，不依赖"觉得可疑"才触发）**
- 触发：节点进入因果链（前向/反向首分歧、首显形、污染点、现象终点）。
- 程序：列出其**全部操作数**并逐一溯源：①本侧语义生产者的输出四元组 ≟ 该操作数四元组（同侧自比）；②对侧同名节点同位操作数的分布性质（有界性/量级/dtype 来源）是否一致。**参数/权重派生张量**（位置嵌入、常量表、旋转编码等）与输入数据无关，其跨侧分布性质差异是单侧异常的有效证据；"两侧输入数据不同→跨侧不可比"的豁免只适用于输入数据的直接传播链。③**张量同一性指纹**是关系型证据，对局部统计失真鲁棒，发现即优先核查：某操作数的统计与同 dump 内另一节点输出完全一致（疑似传错张量/缓冲区别名）；同侧"生产者输出 ≠ 消费操作数"而对侧两者一致。发现任一指纹时，必须按统计四元组反查生产者，把"谁把它传进来的"作为根因候选核查，不得以"该区域统计可能失真"折扣。④"异常局限于某段/某趟"与"某段干净"的结论必须以跨侧对应节点对比为依据；单侧内部自洽不是跨侧证据。

## HC-E 表述与结论纪律

**HC-E1 术语与独立性**
- 已证实：当前材料直接支持。合理推断：机制合理且有部分证据，关键环节未直接观测。待验证：有可检验假设但证据不足。已排除：有具体证据与观测不符。未检查：尚未检查，不得声称已排除。
- 多个差异指标同源不算独立证据；多个 rank 相似异常但共享上游不算独立印证。
- 计数类声明写明过滤谓词，保证可复算。
- 结构性分歧（dtype/值域/有无）与内容性数值分歧是不同指纹类，不得因执行序相邻或语义相关就并入同一条因果链；确需并轨时必须证明张量同一性或给出消费点证据。

**HC-E2 置信度纪律**
- 证据强度（强/中/弱 + 一句依据：存在性/复现性/反证完备度）与"作为根因"置信度（高/中/低）**分句给出**。置信度标注不得使排序产生相反的操作性效力（如第 1 位标"低（作为根因）"而第 2 位标"高（作为根因）"）。
- **主候选自我反证义务**：主候选因果链对其可观测后果的预测，须与实测分布做一次槽位级一致性核对（例："若为未清零残留，则凡有本步产出的槽位也应携带残留"——实测若有产出槽位零残留、仅无产出槽位持值，该矛盾必须先调和才能定稿）；预测-实测矛盾未调和时主候选不得标"高置信"，且矛盾本身可能指向替代机制（如实报告）。
- 不得用"某候选不能解释现象量级"为由降级一个机制环节在覆盖外的候选，也不得以对覆盖外路径的量级"闭合"叙事作为覆盖外假设的独立加分——不可观测路径的贡献既不可证实也不可证伪，此类量级论证自身无证据地位。

**HC-E3 输出数量与实例纪律**
- 深入验证的候选 ≤5 个（不设下限，宁少而准；候选数量只约束深入验证名额，不封闭探索空间——新证据表明排序不合理时及时替换）。
- 候选按机制归组，但展示必须按**具体节点实例**逐个列出（dump 原始节点名+调用号+order），不得以"族"作展示主语，不得用紧凑区间替代实例清单（区间只能作补充汇总；代表节点与数值/栈帧形态独立的成员必须完整精确单列）。
- 已排除/降权项与速览锚点结案条目逐条锚定精确 API 节点名（含调用号）；"族"只作条目内的证据语境；无节点名的族级结案禁止；速览高置信锚点逐条结案，不并入族。**落盘位置**：结案条目落 evidence.json `exclusion_ledger`（item/type/disposition/basis 四格），报告不再设排除台账章节。
